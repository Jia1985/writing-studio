# The Writing Studio

A private, atmospheric place to write and read in the browser. Pick a room — a
city study, a forest cabin, a seaside café, an old library, or a fireside
reading nook — and type on the typewriter, write by hand, or read a book by the
fire. Everything moves and sounds like the room it is: rain on the glass, waves
and gulls, a log fire, a ticking clock, records on the turntable.

Your writing stays in your own browser (IndexedDB); nothing is uploaded.

## Run it

```bash
node server.js
```

Then open http://127.0.0.1:5178.

## Music

MP3s in `assets/music/` become records on the turntable. Name them in
`assets/music/records.json`; any file not listed there is named from its filename.
